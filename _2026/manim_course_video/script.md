# 用 Manim 做課程影片：AI 協作工作流

約 5 分鐘（畫面總長 4:50，配音後依實際語速微調 `self.wait()`）。
這支影片本身就是用片中介紹的 manim-pipeline 做的：先寫這份旁白，再寫 `main.py`。

## 算圖 Render

```bash
# 預覽單一章節
manimgl _2026/manim_course_video/main.py Pipeline -p
# 全部輸出成檔
manimgl _2026/manim_course_video/main.py Intro Pipeline DivisionOfLabor ParallelAgents IterationLoop Pitfalls Outro -w
```

- 中文字型用 `CJK_FONT`（預設 `Noto Sans CJK TC`），沒有就改成本機有的字型。
- 全片只用 `Text`，不需要安裝 LaTeX。

## 配樂 Background music

```bash
# 合成 4:50 的無版權配樂（72 BPM，Cmaj7–Am7–Fmaj7–G6）
python _2026/manim_course_video/make_bgm.py bgm.wav 290
```

- 結構對齊章節：Intro 只有和弦 pad，0:34 起加入 bass 與琶音 arpeggio，4:12 起收掉琶音，最後 6 秒淡出。
- 混音時配樂壓在旁白下方約 -18 至 -22 dB，人聲出現時再自動壓低（ducking）。

| # | Scene | 長度 | 重點 |

| 1 | `Intro` | 0:34 | 常見問題 → 示範動畫 → 標題與三個關鍵字 |

### 1. Intro（0:00–0:34）

> 最近常有人問我三個問題：這種數學動畫是怎麼做的？一定要很會寫程式嗎？AI 到底能幫上什麼忙？
>
> 答案是 Manim，一個用 Python 寫動畫的工具。像這條正弦曲線、這個正方形變成圓，全部都是程式畫出來的。
>
> 今天用五分鐘，帶你看我怎麼跟 AI 一起做課程影片。三個關鍵字：流水線、分工模式、迭代。
>
> 順帶一提，你現在看的這支影片，就是用這套流程做出來的。

### 2. Pipeline（0:34–1:19）

> 我把做一支影片拆成六個站：企劃、腳本、分鏡、程式、算圖審片，最後是配音剪輯。
>
> 每一站都會留下一個產出物：學習目標、旁白稿、Scene 清單、程式檔、預覽影片，最後是成片。這些檔案就是你的知識資產，下次直接拿來改。
>
> 真正花時間的地方，是「程式」跟「審片」之間的迴圈：寫、看、改，改到滿意為止。
>
> 最重要的一條規則：先寫旁白，再寫程式。畫面跟著聲音走，不是聲音去追畫面。

### 3. DivisionOfLabor（1:19–2:08）

> 那人跟 AI 怎麼分工？我把自己當導演，AI 當動畫師。
>
> 看每一站的比例：企劃幾乎都是人，因為「要教什麼、教給誰」只有你知道。腳本跟分鏡一半一半，AI 很會幫你潤稿、拆段落。到了程式，AI 做掉八成以上。審片要靠你的眼睛，配音剪輯也主要是你。
>
> 一句話記起來：人決定 What 跟 Why，AI 負責 How。
>
> 在這個流程裡，最稀缺的是品味，不是打字速度。

### 4. ParallelAgents（2:08–2:47）

> 分工模式還可以再進一步：一個 Scene 交給一個 Agent。
>
> 分鏡切好五個 Scene，如果一個人從頭做到尾，要花五份時間。交給三個 Agent 同時開工，大概兩份時間就完成。
>
> 但有個前提：大家要用同一套規範。顏色、字型放在 style 檔，共用的 helper 函式統一寫好，寫法規則放在 CLAUDE.md。
>
> 沒有規範的平行，只會得到五種畫風。

### 5. IterationLoop（2:47–3:30）

> 實際走一輪。我說：「畫一個正方形，變成藍色的圓。」AI 寫出程式，我按預覽，看一下。
>
> 嗯，太快了。我回饋：「慢一點，再加個標題。」AI 只改兩個地方：加上 title，把 run_time 設成三秒。再預覽一次，這次對了。
>
> 兩個工具讓迴圈更快：用 -se 加行號，停在那一行互動除錯；用 checkpoint_paste，只重跑你改動的段落。
>
> 每一輪一到兩分鐘，小步快跑。

### 6. Pitfalls（3:30–4:12）

> 四個新手最常踩的坑。
>
> 第一，一個 Scene 塞太多。一個 Scene 只講一件事，平行分工跟重做都比較容易。
>
> 第二，沒有旁白就開始畫。先把旁白長度定下來，再用 self.wait 對時間。
>
> 第三，字型跟 LaTeX 沒先測。第一天就算一張測試圖，設定問題早爆早好。
>
> 第四，每次都從零開始。把好用的 prompt 跟 helper 存成模板。

### 7. Outro（4:12–4:49）

> 今天就能開始的三步：挑一個三分鐘講得完的概念，先寫旁白；拆成三到五個 Scene，交給 AI 寫第一版；然後你只做一件事，看預覽、給回饋。
>
> 每做完一支，就把流程裡的產出物存進模板庫，你會越做越快。
>
> 記住：你當導演，AI 當動畫師。

## 給 AI 的分工提示 Prompt templates

**寫單一 Scene（交給一個 Agent）**

```text
請在 _2026/manim_course_video/main.py 新增 Scene `<名稱>`。
旁白：<貼上這一段旁白>
長度：約 <秒數> 秒，用 self.wait() 對齊旁白。
規範：沿用檔案頂端的顏色常數與 zh()、get_card()、get_pipeline() 等 helper，不要新增字型或配色。
```

**審片回饋**

```text
<Scene 名稱> 在 <秒數> 附近：<哪裡不對>。只改這個問題，其他保持不變。
```
